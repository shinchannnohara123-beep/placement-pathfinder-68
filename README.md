# Remix 3 of Placement Navigator

MASTER PROMPT – Build "PlacementPilot" (AI-Powered Placement Preparation Platform)

You are an expert Product Designer, Senior Full Stack Developer, UI/UX Designer, Database Architect, and AI Engineer.

Build a complete production-ready web application named PlacementPilot.

This is NOT a college CRUD project.

It should look and feel like a premium SaaS product (similar quality to Notion, Linear, GitHub, Duolingo, and Coursera).

The design should be modern, clean, responsive, animated, and beautiful.

Primary Goal

Create an AI-powered Placement Preparation Platform that acts as a personal mentor, study planner, placement tracker, company research assistant, resume manager, and interview preparation system.

The platform should guide students from the beginning of college until they receive a placement offer.
